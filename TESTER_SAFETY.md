# s2wkjb tester safety sheet

Read this before running any test, especially any test in the
Danger / Kernel tab. Do not run a test you do not understand.

## Risks, in plain language

- Ban: your account, your console, or both can lose online access.
  An alternate account does not protect a console from a console ban.
- Soft brick: the console will not boot normally, often fixable by
  recovery or reflashing the original OS, with possible save loss.
- Hard brick: boot chain or NAND corrupted, console may not boot
  at all. This is the main risk in the Danger tab.
- Data loss: saves, game data, or system data can be corrupted
  even if the console still boots.

## Before you test, check all of these

- [ ] This is NOT my primary Switch.
- [ ] This is NOT my primary Nintendo Account.
- [ ] I have backed up saves and anything I care about.
- [ ] I understand a hard brick is possible, even if unlikely.
- [ ] I will stay offline while testing (airplane mode, no eShop,
      no online play, no Nintendo servers while testing).
- [ ] I know I can say no to any specific test, at any time.
- [ ] I understand a crash is not an exploit, and I will report
      crashes accurately, not as a confirmed jailbreak.

## Tester agreement

By running a test, you confirm you read the risks above, you are
using a spare console you can afford to lose, and you accept that
the developer cannot undo a ban or a brick for you.

If you are not comfortable with any item above, do not run the test.
